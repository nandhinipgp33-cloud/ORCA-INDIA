# Data Sources

## Research status

No external ocean-data provider is connected in the foundation milestone. Do not interpret the dashboard's API health status as data-source availability.

Before integration, each candidate provider and product will be checked against its official documentation for product identity, endpoint or download mechanism, authentication, geographic and temporal coverage, resolution, refresh cadence, format, licensing, quality flags, and known limitations.

Candidate research areas include INCOIS, ISRO MOSDAC, NASA Ocean Color, Copernicus Marine Service, and other relevant official Indian marine and meteorological sources. No credentials, dataset IDs, or endpoints are assumed here.

Sample or mock values, if later needed for UI development, must be separately labelled as development fixtures and never presented as observations.
